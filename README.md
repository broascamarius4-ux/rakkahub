# Rakka Hub

Windows desktop hub for games, apps, Spaces, Sound Pad, notes and saved videos.

## Download

Download the latest **Rakka-Hub-...-setup.exe** from [Releases](https://github.com/broascamarius4-ux/rakkahub/releases/latest).

Supports 64-bit Windows. Rust, Node.js and Python are not required to run the installed app. Windows may show an unrecognized-app warning because the installer does not yet have an Authenticode certificate.

Version 0.2.2 adds signed in-app updates. Install this version manually once if you are using 0.2.1 or older. Future updates appear in the upper-right corner with **Update** and **Later**; **Update** downloads, verifies, installs and reopens Rakka.

This repository contains release downloads and update metadata. Application source is maintained separately. Update signatures verify authenticity; they are separate from Windows code signing.
